# Library Management System

A frontend-only Library Management System built with React.js, JavaScript, HTML, and CSS.

## Features
- Dashboard with book and student statistics
- Book and student management
- Issue and return books
- Student-wise tracking
- Overdue book tracking
- Book availability search
- LocalStorage for saving data in the browser

## Run Locally
```bash
npm install
npm run dev
```

## Tech Stack
- React.js
- JavaScript
- HTML
- CSS
